# Aerviora

**Personalised environmental guidance for better outdoor decisions.**

Aerviora is a mobile-first environmental decision-support prototype developed for IEEE Curtin ASPIRE 2026.

It combines environmental conditions with user context to produce explainable concern levels, practical guidance, and lower-risk timing recommendations.
